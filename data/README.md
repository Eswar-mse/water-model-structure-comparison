# Featured plot data

`domain_distances.csv` is a byte-for-byte copy of `03_distances/distances_all.csv` from the original results folder (SHA-256 `e12e0212d79feeab32b217f6aff0c06b3e5e8b85bab5a23bbba2849074fec295`). It contains 30,001 frames for each of eight conditions, from 0 to 300 ns in 0.01 ns steps.

Columns: water model, starting-structure label, frame, time in ns, LID–core distance in Å, and NMP–core distance in Å. The original trajectory and atom-selection code are unavailable here, so this file reproduces the featured occupancy plot but does not independently validate how the distances were calculated.
